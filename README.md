# JIU JI TAE SYSTEM
Fresh offline-first PWA starter. Dark Arabic/English interface, daily quests, XP, levels, rank progression and local progress storage.

## Background image
Add your chosen image of Jiu Ji Tae after awakening to `assets/jiu-ji-tae-awakened.jpg`. The app is already configured to use that exact filename. Use an image you have permission to use. Until then, the hero shows the dark fallback background.

## Publish
Upload the contents of this folder to the root of your GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).
